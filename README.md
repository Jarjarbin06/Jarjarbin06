## 🔹 Engineering Philosophy

My development follows a consistent set of principles:

* deterministic execution over implicit behavior
* modular systems over monolithic design
* explicit memory and lifecycle control (especially in C)
* reproducible environments across projects
* separation of concerns between tools, libraries, and applications
* documentation treated as a structural component of the system
